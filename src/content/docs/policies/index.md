## Using AI, in short

- **Use is expected.** MuleCode is the course default. Other tools are allowed if you say so.
- **Trace it.** Every non-trivial pull request links an iceberg, or names the other tool and attaches its transcript.
- **Understand it.** Anyone on the team can be asked to explain any merged change and its trace.
- **Stay at your stage.** Working above it is a process issue, not an integrity case.
- **Keep secrets out.** Don't paste passwords, keys or tokens into prompts, and read an iceberg before you commit it.
