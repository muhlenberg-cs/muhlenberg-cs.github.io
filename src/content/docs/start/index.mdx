Do these before the first class if you can, and by week 1 Thursday at the latest. Plan on about an hour, most of it waiting for downloads.

<Steps>

1. [GitHub and Classroom](/start/github/): an account, and the course invite.
2. [Install mule](/start/install-mule/): one command on a Mac or on Windows.
3. [Ollama and the model](/start/ollama/): the model runs on your own laptop.
4. [Terminal and font](/start/terminal/): optional, but it makes `mule` easier to read.
5. [Sign in to gh](/start/gh/): the GitHub command line, which `mule` uses for your team's sprint.
6. [Check it all works](/start/check/): three commands.

</Steps>

<Aside type="note" title="Your laptop">
16 GB of RAM is the minimum and 32 GB or more is recommended. MuleCode runs on macOS (Apple Silicon or Intel) and Windows 10/11 (64-bit). If your laptop can't run it, say so in week 1: teams share capable machines, and loaners are available.
</Aside>

If a step fails, don't fight it alone for long. Bring the exact error message to class, or see [Troubleshooting](/mule/troubleshooting/).
