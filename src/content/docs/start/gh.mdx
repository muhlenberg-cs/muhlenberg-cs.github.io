---
title: 5. Sign in to gh
description: Sign in to the GitHub command line, which MuleCode uses to show your team's sprint.
---

`gh` is GitHub's command line, and step 2 installed it. MuleCode's sprint sidebar and `/next` command use it to read your team's issues and milestones. You'll also use it to open pull requests.

```bash
gh auth login
```

Answer the prompts with **GitHub.com**, **HTTPS**, **Yes** (to authenticate Git with your GitHub credentials), and **Login with a web browser**. Copy the one-time code it shows, then approve it in the browser.

If your team's sprint board doesn't show up later, your sign-in may be missing the `project` permission. Add it with:

```bash
gh auth refresh -s project
```

Check it with `gh auth status`. It should say you're logged in to github.com as your username.
